# Cordes sympathiques

Six compositeurs, six pages à lire et à écouter : Bach, Mozart, Beethoven, Chopin, Liszt et Brahms,
reliés par une page d’accueil où leurs vies vibrent comme des cordes sympathiques.

Site statique, sans dépendance ni compilation : chaque dossier contient une page autonome et sa musique.

| Dossier | Page |
|---|---|
| `/` | Cordes sympathiques (accueil) |
| `bach/` | À un jour-lumière |
| `mozart/` | L’Étourneau de Mozart |
| `beethoven/` | Beethoven, l’oreille intérieure |

| `liszt/` | Lisztomanie |
| `brahms/` | Brahms en cinq lignes |
